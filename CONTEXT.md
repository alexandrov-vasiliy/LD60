# Игровые понятия

## Language

**Ходьба**:
Перемещение персонажа по земле вперёд, назад и в стороны относительно горизонтального направления взгляда. Наклон взгляда вверх или вниз не задаёт вертикальное движение.

**Обзор**:
Изменение направления взгляда персонажа независимо от ходьбы.

**Шаг**:
Завершённый отрезок фактической горизонтальной ходьбы по земле заданной длины. Остановка сбрасывает незавершённый отрезок; поворот на месте, упор в стену и падение шагами не считаются.

**Отклик шага**:
Общий настраиваемый эффект, воспроизводимый при каждом шаге независимо от ноги и поверхности.

**Предмет**:
Отдельный объект мира, который можно подобрать, хранить в слоте и выбросить обратно в мир.

**Тип предмета**:
Вид предмета, общий для всех его экземпляров. Два предмета одного типа остаются двумя отдельными предметами.
_Avoid_: Уникальный ID экземпляра

**Инвентарь**:
Набор слотов персонажа с настраиваемой вместимостью; по умолчанию содержит три слота.

**Слот инвентаря**:
Место для одного предмета. Одинаковые предметы занимают отдельные слоты.

**Активный слот**:
Выбранный слот инвентаря, предмет которого персонаж держит в руке. Активный слот может быть пустым.

**Выброс**:
Возвращение предмета из инвентаря в мир, где он снова движется под действием физики.
